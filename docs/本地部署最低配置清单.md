# Video Content Analyzer — 本地部署最低配置清单（Windows / macOS）

> 编制日期：2026-08-02
> 适用版本：单体 Flask 后端（`transcribe_server.py`）+ 静态前端（`web_player.html`）
> 数据来源：实测当前项目 venv 体积（961 MB）、Whisper 模型缓存、代码运行时参数

---

## 0. 先说清楚：这个项目真正吃的是什么

| 真相 | 说明 |
|------|------|
| **不需要 GPU** | 代码第 117 行 `whisper.load_model(model_name, device="cpu")` 硬编码 CPU。Apple Silicon 的 MPS、NVIDIA 的 CUDA 当前都**没用上**，纯靠 CPU 推理。 |
| **不需要单独装 ffmpeg** | 项目用 `imageio-ffmpeg` 自带 ffmpeg 二进制，音视频提取不依赖系统 PATH。 |
| **真正的瓶颈是 CPU + 内存** | Whisper 语音转写是 CPU 密集型；模型加载 + 推理峰值吃内存。 |
| **LLM 拆解走 API** | 深度拆解默认调 SiliconFlow / 智谱（云端），需联网 + API Key；也可切 Ollama（本地跑，额外吃内存）。 |
| **默认模型是 `small`** | 中文识别较好，但体积 462 MB、CPU 推理最慢。低端机可换 `tiny`（73 MB，快但精度低）。 |

## 1. 通用必装项（Win / Mac 一样）

| 项目 | 要求 | 备注 |
|------|------|------|
| Python | **3.10 – 3.12**（推荐 3.11） | ⚠️ 暂不建议 3.13，部分 torch 轮子跟进滞后 |
| pip 虚拟环境 | 必须（venv） | 实测依赖装完占 **961 MB** |
| 浏览器 | Chrome / Edge / Safari / Firefox 任一 | 前端是纯静态 HTML，现代浏览器即可 |
| 网络 | 出网能力 | LLM 云端 API 需要；纯转写可不联网 |
| 磁盘可用空间 | 见第 4 节明细 | 最低 4 GB，推荐 10 GB+ |

## 2. Windows 最低配置清单

| 维度 | 最低可运行（tiny 模型） | 推荐流畅（small 默认模型） |
|------|------------------------|----------------------------|
| **系统** | Windows 10 64 位（19041+） | Windows 11 64 位 |
| **CPU 架构** | **x86-64（Intel/AMD）** | 同左 |
| **CPU 规格** | 双核 2.0 GHz 及以上 | 四核 i5（8 代+）/ Ryzen 5 同级 |
| **内存** | 8 GB | **16 GB** |
| **磁盘** | 4 GB 可用（SSD 优先） | 10 GB 可用 SSD |
| **GPU** | 不需要 | 不需要（可选 CUDA 加速，见第 6 节） |
| **运行时** | VC++ 2019 可再发行组件 | 同左（torch 可能需要） |

> ⚠️ **Windows on ARM 不支持**（Surface Pro X 等）：torch CPU 轮子无官方 ARM64 Windows 支持，Whisper/MKL 会崩。必须 x64 机器。

## 3. macOS 最低配置清单

| 维度 | 最低可运行（tiny 模型） | 推荐流畅（small 默认模型） |
|------|------------------------|----------------------------|
| **系统** | macOS 12 Monterey+ | macOS 13 Ventura+ |
| **芯片** | Apple Silicon（M1）或 Intel Mac（2018+） | **Apple Silicon M1/M2/M3** |
| **CPU** | 双核（M1 基础款即可） | M 系列 8 核 GPU/CPU 统一内存 |
| **内存** | 8 GB | **16 GB**（统一内存，转写+浏览器共享） |
| **磁盘** | 4 GB 可用 | 10 GB 可用 |
| **GPU** | 不需要 | 不需要（M 系列靠 CPU 推理已够快，见第 6 节） |

> 💡 Apple Silicon 优势：M1 及以上用 CPU 跑 small 模型比同档 Intel 笔记本快且省电；当前虽未启用 MPS，纯 CPU 路径在 macOS 上已表现良好。

## 4. 磁盘占用明细（实测）

| 组成部分 | 体积 | 是否必需 |
|----------|------|:--:|
| Python venv（含 torch 490 MB） | **961 MB** | ✅ 必需 |
| Whisper `tiny` 模型 | 73 MB | 可选（最快） |
| Whisper `small` 模型（默认） | **462 MB** | ✅ 默认加载 |
| Whisper `medium` 模型 | 296 MB | 可选（最准最慢） |
| 后端 + 前端 + 文档代码 | < 5 MB | ✅ 必需 |
| 视频临时解包 + 导出包 | 视视频大小，单个 600 MB 视频约 1–2 GB 峰值 | 运行时产生 |

**结论**
- 用 `tiny`：app 约 **1.1 GB**，最低磁盘留 **4 GB** 即可。
- 用 `small`（默认）：app 约 **1.5 GB**，建议留 **10 GB**（含视频处理峰值）。

## 5. 一键部署步骤（Win / Mac 通用）

```bash
# 1. 建虚拟环境（Python 3.11）
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # macOS

# 2. 装依赖（实测 ~961 MB）
pip install -r backend/requirements.txt

# 3. 启动（默认 small 模型，8766 端口）
cd backend
python transcribe_server.py --host 0.0.0.0 --port 8766

# 4. 浏览器打开
#    http://127.0.0.1:8766/
```

> 低端机想更快？启动时加 `--model tiny` 换轻量模型；或前端下拉框选 Tiny。

## 6. 可选加速（非最低配置，但值得知道）

| 方案 | 平台 | 效果 | 改动成本 |
|------|------|------|----------|
| NVIDIA CUDA | Windows / Linux | small 模型提速 3–5 倍 | 改 `device="cpu"` → `device="cuda"`，装 CUDA 版 torch |
| Apple MPS | macOS | M 系列提速 2–3 倍 | 改 `device="cpu"` → `device="mps"`（一行） |
| Ollama 本地 LLM | Win / Mac | 深度拆解不依赖云端，数据不出机 | 额外吃 4 GB+ 内存跑 7B 模型 |

> 当前版本三者都**未启用**，纯 CPU 也能跑，只是大视频转写慢。

---

## 7. 常见踩坑提醒

1. **别用 Python 3.13**：torch/whisper 轮子对 3.13 跟进慢，优先 3.11。
2. **Windows 必须是 x64**：ARM 版 Windows 装不了 torch CPU 轮子。
3. **内存小于 8 GB 会卡**：small 模型加载 + 浏览器 + 系统，8 GB 是底线。
4. **机械硬盘能跑但慢**：模型加载和视频解包在 HDD 上明显拖速，SSD 体验好很多。
5. **LLM 拆解要联网**：用 SiliconFlow / 智谱需 API Key + 出网；离线场景请切 Ollama 本地。
