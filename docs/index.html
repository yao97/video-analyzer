Features

核心功能

六大 Tab 覆盖「转写 → 智能分析 → 拆解 → 报告 → 历史」全链路，每个产出都可直接用于编导工作流。

🗣️ 语音转写 · Qwen3-ASR

Qwen3-ASR-1.7B 本地大模型转写，DirectML/Vulkan GPU 加速、字级时间戳；实时进度百分比与剩余时间预估；输出分段文本并自动提取高频词 / 动作词 / 情绪词 / 产品词。

Qwen3-ASR-1.7B（本地） GPU DirectML / Vulkan 
# 上传 → 提取音频 → 启动转写 → 结果
POST /api/transcribe          → job_id（提取音频）
POST /api/transcribe-start    → 启动 Qwen3-ASR
GET  /api/status/{job_id}     → extracting / audio_ready / transcribing / done
# 附带 current_chunk：逐词实时文本（转写中可见）+ chunk_chars 字符数
GET  /api/result/{job_id}     → segments[] + keywords{}

# 示例输出
[0.0s-3.0s] 家人们，今天给大家推荐一款非常好用的产品
[3.0s-6.0s] 它真的特别棒，用过都说好
# keywords: {highFreq:[推荐,产品], actions:[推荐,点击]}

Quick Start

快速开始

# 1. 本地运行（需 Python 3.10+ 与 ffmpeg）
pip install -r backend/requirements.txt
cd backend && python transcribe_server.py --host 0.0.0.0 --port 8766 --model small

# 2. 浏览器打开
http://localhost:8766/

# 3. Docker 部署
cp .env.example .env   # 填 LLM_API_KEY / LLM_PROVIDER
docker compose up -d --build
